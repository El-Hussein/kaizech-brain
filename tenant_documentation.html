Platform Overview & Architecture

Multi-Tenant Isolation pgvector 1536 Real-Time Redis Cache

Kaizech Brain is an enterprise multi-tenant AI Agent platform engineered for customer support, domain knowledge retrieval, autonomous workflow execution, and multi-platform conversational deployment.

Strict Tenant Isolation
Every tenant operates inside an isolated logical workspace. Vector embeddings, chat histories, tool manifests, and learning rules are partitioned by tenantId.
Hybrid Retrieval (RAG)
Combines dense cosine similarity via pgvector with BM25 keyword re-ranking, ensuring 99.9% domain factual precision and zero hallucination.
Streaming Engine (SSE)
Sub-180ms Time-To-First-Token via Server-Sent Events stream, providing snappy user experience on Web, WhatsApp, and Mobile clients.
Architecture Note: All API requests require authentication via the x-api-key HTTP header. Each tenant receives a production key (kb_live_...) and can rotate credentials anytime via Settings.

Autonomous AI Memory & Continuous Learning

Self-Learning Engine Human-in-the-Loop Automatic Rule Extraction

Kaizech Brain doesn't remain static after deployment. Its background learning engine continuously analyzes live customer conversations to identify unresolved inquiries, recurring complaints, and intent gaps. It then autonomously synthesizes Candidate Business Rules with confidence scores and reasoning explanations.

1. Unhandled Intent Detection
The AI flags moments where customers asked questions that couldn't be answered by existing docs.
2. Rule Synthesis & Confidence
Extracts precise guidelines (e.g. "When asking about weekend delivery, specify Cairo orders ship Saturday") with a 0.0-1.0 confidence score.
3. Human Validation (Approve / Edit / Reject)

Developer REST & Streaming API Reference

Standard JSON API Server-Sent Events (SSE)

Integrate Kaizech Brain into your custom applications, backend microservices, or mobile apps using our REST API or real-time streaming endpoint.

A. Real-Time Token Streaming Endpoint (SSE)

For low-latency UI experiences, consume tokens via POST /api/v1/conversations/stream:

JavaScript / TypeScript: Streaming Fetch
async function streamChat(message, sessionId) {
  const res = await fetch('https://kaizech-brain-production.up.railway.app/api/v1/conversations/stream', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': 'kb_live_your_secret_api_key_here'
    },
    body: JSON.stringify({ message, sessionId })
  });

  const reader = res.body.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value);
    console.log('Received Token:', chunk);
  }
}
