Platform Overview & Architecture

Multi-Tenant Isolation

Kaizech Brain provides isolated environments for tenant organizations. Each tenant operates with dedicated knowledge bases, custom system prompts, authentication keys, and API tool manifests.

Isolated Architecture: All database entities maintain strict tenant_id isolation, guaranteeing vector data, user profiles, and chat logs are completely separated.
⚡ Real-time RAG Engine
PostgreSQL pgvector extension performing cosine similarity search (1536 floats) over uploaded documents.
🛠️ API Function Calling
Allows the LLM to trigger tenant REST APIs on demand to fetch live data or execute business operations.
🔐 Meta Webhook Security
HMAC SHA-256 (X-Hub-Signature-256) verification ensuring valid incoming WhatsApp messages.
📊 Token & Cost Tracking
Real-time breakdown of prompt and completion tokens with estimated USD cost metrics.

Teaching the Model (Knowledge RAG)

Vector Ingestion

To ensure accurate, zero-hallucination answers, feed your company data into the Knowledge Base using three supported methods:

📄 Document Files
Upload .pdf, .docx, .xlsx, or .md manuals and policies.
❓ FAQ Key-Value Pairs
Direct Q&A pairs for high-precision matching (e.g. refund rules, operating hours).
🌐 Website Crawler
Scrapes HTML content from public documentation or help center web pages.
Chunk Inspector Feature: In the Knowledge tab, click View Chunks on any source to inspect extracted text snippets and verify chunk indexing quality.

System Prompt Builder System

Persona & Rules

Configure how your AI Agent responds, what tone it uses, and what safety guardrails it enforces using our structured 10-block builder:

PROMPT_STRUCTURE.txt 
1. === SYSTEM IDENTITY ===          (Define bot persona and primary role)
2. === BUSINESS CONTEXT ===         (Name, Timezone, Supported Languages)
3. === BUSINESS RULES & POLICIES ===(Auction bidding, refund rules, working hours)
4. === SAFETY & COMPLIANCE RULES ===(Prohibit revealing OTPs, keys, credentials)
5. === TONE OF VOICE ===            (Professional, empathetic, concise)
6. === SPECIAL INSTRUCTIONS ===     (Formatting rules, bullet points)
7. === RETRIEVED KNOWLEDGE BASE === (Dynamically injected pgvector RAG chunks)

Custom API Tools Integration

Real-Time Backend Calls

Register REST API endpoints that the AI Agent can invoke autonomously to fetch live data (e.g. user details, auction status) or perform actions.

SAMPLE_TOOL_MANIFEST.json 
{
  "name": "getUserInfo",
  "description": "Fetches user profile details given their unique customer ID.",
  "apiEndpoint": "https://api.yourdomain.com/v1/users/profile",
  "httpMethod": "POST",
  "authType": "bearer",
  "parameters": {
    "type": "object",
    "properties": {
      "userId": { "type": "string", "description": "User unique ID" }
    },
    "required": ["userId"]
  }
}

Embed AI Chatbot SDKs & Web Widget

Multi-Platform SDK Family

Kaizech Brain provides a complete SDK family to embed your trained AI bot on any platform with minimal integration effort.

1. Vanilla JS Script Snippet (<script>)

Drop this snippet into any HTML page, WordPress, Shopify, Webflow, or PHP website. Uses Web Components & Shadow DOM to prevent style leakage:

INDEX.HTML (SCRIPT EMBED) 
<!-- Kaizech AI Chatbot Widget -->
<script>
  window.KaizechChatConfig = {
    apiUrl: "https://your-brain-domain.com",
    apiKey: "kb_live_your_api_key",
    theme: {
      primaryColor: "#0066FF",
      position: "bottom-right",
      botTitle: "AI Assistant",
      welcomeMessage: "Hello! How can I help you today?"
    }
  };
</script>
<script src="https://your-brain-domain.com/widget.js" async defer></script>

2. React Web SDK (@kaizech/chat-react)

For Next.js, Vite, Remix, or Create React App projects:

REACT_EMBED.tsx 
import React from 'react';
import { KaizechChatProvider, ChatWidget } from '@kaizech/chat-react';

export default function Layout({ children }) {
  return (
    <KaizechChatProvider
      apiUrl="https://your-brain-domain.com"
      apiKey="kb_live_your_api_key"
      theme={{ primaryColor: "#0066FF", position: "bottom-right" }}
    >
      {children}
      <ChatWidget />
    </KaizechChatProvider>
  );
}

3. React Native Mobile SDK (@kaizech/chat-react-native)

Native mobile components built with React Native primitives for iOS & Android:

MOBILE_SUPPORT.tsx 
import React from 'react';
import { SafeAreaView } from 'react-native';
import { KaizechChatScreen } from '@kaizech/chat-react-native';

export default function SupportScreen() {
  return (
    <SafeAreaView style={{ flex: 1 }}>
      <KaizechChatScreen
        apiUrl="https://your-brain-domain.com"
        apiKey="kb_live_your_api_key"
        theme={{ primaryColor: "#0066FF", botTitle: "Mobile Support AI" }}
      />
    </SafeAreaView>
  );
}

Direct REST API Reference

REST Chat Endpoint

Send messages directly from your web or mobile app using your secret tenant API key:

POST /api/v1/channels/chat 
curl -X POST "https://your-brain-domain.com/api/v1/channels/chat" \
  -H "Content-Type: application/json" \
  -H "x-api-key: kb_live_your_secret_api_key_here" \
  -d '{
    "message": "What are your operating hours?",
    "sessionId": "session_user_98765"
  }'
RESPONSE_PAYLOAD.json 
{
  "reply": "Our operating hours are Sunday to Thursday, 9:00 AM to 6:00 PM (AST).",
  "sessionId": "session_user_98765",
  "tenantId": "c39e248b-821a-4d7a-8b1e-089a85012345",
  "status": "active",
  "handedOff": false
}

Pause AI & Trigger Human Handoff Endpoint

Manually pause AI and transfer the conversation to human support from your client app:

POST /api/v1/channels/handoff 
curl -X POST "https://your-brain-domain.com/api/v1/channels/handoff" \
  -H "Content-Type: application/json" \
  -H "x-api-key: kb_live_your_secret_api_key_here" \
  -d '{
    "sessionId": "session_user_98765",
    "reason": "client_requested"
  }'
